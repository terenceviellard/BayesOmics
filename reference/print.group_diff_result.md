# Print a Group-Difference Result

Prints the metric that was used (see
[`group_diff`](https://terenceviellard.github.io/BayesOmics/reference/group_diff.md)),
then the underlying matrix.

## Usage

``` r
# S3 method for class 'group_diff_result'
print(x, ...)
```

## Arguments

- x:

  A `group_diff_result` object, from
  [`group_diff`](https://terenceviellard.github.io/BayesOmics/reference/group_diff.md).

- ...:

  Unused, included for S3 consistency.

## Value

`x`, invisibly.
