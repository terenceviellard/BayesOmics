# Partition IDs by Density-Based Clustering (Reserved, Not Implemented)

Placeholder for an automatic, density-based partition strategy.
Constructing this object is allowed (so it can be passed around and
inspected), but
[`resolve_partition`](https://terenceviellard.github.io/BayesOmics/reference/resolve_partition.md)
always errors on it – auto-detection is not implemented yet.

## Usage

``` r
partition_dbscan(eps, minPts, ...)
```

## Arguments

- eps:

  Reserved.

- minPts:

  Reserved.

- ...:

  Reserved.

## Value

A `partition_strategy` object that always errors when resolved.
